# Project Template

## Problem

What decision or workflow improves if this system works?

## Non-goals

What is intentionally outside the scope?

## Architecture

How does data move through the system, and where does failure occur?

## Design Decisions

What alternatives were considered, and why was this approach selected?

## Evaluation

How are correctness, safety, reliability, and user value measured?

## Run Locally

Provide exact commands with no hidden credentials.

## Limitations

Describe missing integrations, scale assumptions, operational risks, and next steps.
